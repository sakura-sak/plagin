# Антиплагиат БГУИР

Плагин типа `plagiarism` для Moodle 4.1–5.3. Сравнение документов выполняет сайт
«Антиплагиат БГУИР»; этот модуль передаёт файл по REST API и показывает проценты.

Компонент: `plagiarism_antiplagiat`  
Каталог на сервере: `<moodle>/plagiarism/antiplagiat`

## Установка ZIP

1. Загрузите `plagiarism_antiplagiat-1.2.2.zip` (внутри папка **`antiplagiat`**).
2. Администрирование сайта → Плагины → Установить плагины → загрузить ZIP  
   либо скопировать папку `antiplagiat` в `<moodle>/plagiarism/antiplagiat`.
3. Пройти обновление БД.
4. Дополнительно → Плагины обнаружения заимствований → включить подсистему и этот плагин.
5. Открыть `/plagiarism/antiplagiat/settings.php` **или** сразу прописать URL и ключ в
   `config-guard.php` на сервере Moodle (тот же ключ, что `MOODLE_API_KEY` в Guard).
   URL должен открываться **с сервера Moodle**, не `localhost`, если Guard на другой машине.
6. На странице настроек нажать «Проверить связь с Guard».
7. Cron Moodle должен работать.

Если Guard недоступен, плагин всё равно установлен: статус у файла «в очереди» или ошибка связи.

Подробно в комплекте поставки: `установка-в-moodle/КАК-ПОДНЯТЬ-И-ПРОВЕРИТЬ.md`
